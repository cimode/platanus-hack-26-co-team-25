# Batch 1 — image prompts (20)

Generated by the `create_quest` workflow. Source of truth: `quiz/batch-1.json` —
if the two disagree, the JSON is right and this file is stale.

**Four images per block, one per option.** The option text is baked into the image as a
centered bold caption. Blocks 1–5 of 15; the reversed-keyed option is marked in each table.

## Shared style token

Every prompt below already opens with this string — it is prepended verbatim, not a template:

```
flat vector cartoon, warm palette, thick outlines, square 1:1, bold condensed sans-serif caption centered, high contrast, no other text
```

## Output naming

```
public/quiz/b{block}-{option}.png   # e.g. public/quiz/b1-a.png … b5-d.png
```

Square 1:1. 20 files for this batch, 60 across the full instrument.
